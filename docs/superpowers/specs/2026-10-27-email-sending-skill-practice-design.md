# 邮件发送 Skill 实践设计

## 目标

按照 ICT 1.14 手册完成 Agent 邮件发送 Skill 的安装、配置、发送验证和
比赛作品归档。最终作品目录仅包含手册指定的对话记录与 `readme.md`。

## 方案

直接复用官方 `SendmailSkills`，避免重新实现 SMTP 发送能力。将其
`SKILL.md`、发送脚本和配置模板整理进项目，保存来源与提交版本。

本地配置使用 `accounts.json` 保存邮箱账号和授权码，并通过
`.gitignore` 排除。仓库只保留不含敏感信息的模板。

## 组件

- `skills/sendmail/`：官方 Skill 与发送脚本。
- `tests/test_sendmail_skill.py`：参数校验与 SMTP 发送路径测试。
- `data/recipients.csv`：个性化通知示例数据。
- `Agent办公实践邮件发送Skill实践作品/`：比赛要求的最终归档。

## 数据流

用户给出收件人、主题和正文后，Agent 读取 Skill；脚本解析账号配置，
选择服务商对应的 SMTP 服务器与端口；构造 MIME 邮件；完成登录和
投递；最后返回成功或可读错误。

## 错误处理

- 缺少收件人、主题、正文或账号配置时停止发送。
- 授权码错误时提示使用邮箱授权码而非登录密码。
- SMTP 连接失败时提示检查网络、服务器和端口。
- 附件不存在时停止发送。

## 安全约束

- 不把真实授权码写入代码、日志或公开仓库。
- 没有用户授权码时不向外部邮箱发送真实邮件。
- 验证使用 SMTP 传输替身检查完整 MIME 和登录参数。

## 验收

- 官方 Skill 源码和提交版本可追溯。
- `python -X utf8 -m unittest tests.test_sendmail_skill -v` 全部通过。
- 最终作品目录恰好包含指定的两个文件。
